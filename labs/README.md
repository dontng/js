# 小实验

一个目录只验证一个明确问题，代码和 README 放一起。当前没有已完成实验。

第一项候选为 001-can-receive：根据真实硬件和厂商示例接收信息；条件确认后再创建。不能把未验证的代码写成“已接通设备”。

复制[实验模板](../templates/lab.md)建立 README，记录目标、环境、最少步骤、预期、实际结果、证据、失败分析和下一次修改。无实物时明确标“模拟”，成功运行模拟不能证明物理 CAN FD 链路正常。

每次只增加一个能理解和验证的变化。关键学习验收：自己解释主要代码，独立改一个同类功能，复现并分析一次异常。

真正需要连续使用的实现再整理到[工具区](../tools/README.md)，原实验记录保留并互相引用。
