- 每轮小功能，项目关键代码本人能解释、修改、验证和排错。

## 问题怎样自我迭代

提出问题 → 必要时拆小 → 找到暂定回答 → 自己验证 → 修正结论 → 下一问。
每轮只记“结论、依据、下一问”，不填模板、不写打卡流水账；由AI协助整理。

保留问题编号和父子关系，重复问题合并并注明去向，结论被推翻就重新打开。状态用待解决、推进中、待验证、已解决或暂缓；AI给出回答不能自动算本人掌握。
阶段只是导航，不要求清空所有问题才前进。当前只推进一个主问题，新发现先收集，不自动扩成开发任务。
