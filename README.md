# Joint-Studio

**简称 JS：面向机器人软件工作的学习、实验与工具集合。**

从 CAN 入门出发，结合公开示例、模拟设备与可用设备，逐步掌握 CAN/CAN FD 通信、Python 编程、上位机、自动化测试与 ROS2 接入。未来按实际需求加入仪器适配、设备接口及其他软件工具。

JS 不是单一商业软件，也不是限定在关节模组上的产品。它收纳学习过程和多个小项目；能复用的代码在实际需要时整理。第一条完整主线是：**CAN/CAN FD → 通信程序 → 上位机与自动化 → ROS2 接入**。ROS2 接入是这条主线的阶段终点，也是机器人软件实践的起点。

## 问题驱动的自我迭代

JS不仅存笔记，也保留问题怎样产生、拆分、回答、验证和引出下一问。按照[迭代规则](requirements/ITERATION.md)持续更新需求与阶段问题；本人能解释、修改、验证和排错才算掌握，不以AI生成量代替进步。

## 学习与工作的关系

先从目标岗位提取能力，再在现有工作里找能练习的任务。围绕参考程序的一个功能，观察操作、追踪实现依据、自己完成修改、验证结果并留下经验。衡量进步的是独立解释、修改和排错，而不是收集了多少文件或生成了多少代码。

主语言暂定 Python；参考软件的语言和设备 SDK 尚待确认。ROS2 实践目前优先对齐 Ubuntu 22.04 + Humble，接入时复核；Windows、WSL2 和可选 macOS 的角色见[环境记录](docs/ENVIRONMENT.md)。

## 使用约定

文件名用简短英文，正文用中文；目录按用途分，内容多了再按主题细分。新资料可以先放收件箱，不要求当场整理。AI 生成的解释、示例和完成状态必须区分已验证与待验证。

本仓库公开。只收录可公开的材料与独立实现；公司源码、私有协议、设备配置和日志不直接上传。无需公开的工作资料保留在获准的工作环境，本仓库只记录不涉及敏感信息的方法。

JS 是 Joint-Studio 的简称，不表示采用 JavaScript 技术栈。

## 提交记录

每次 AI 交付按[提交规范](docs/COMMIT_POLICY.md)记录执行者、具体修改、原因及验证。支持区分 GPT/Codex、Antigravity、Gemini 与 Claude。本地克隆后运行 `bash scripts/setup-git-policy.sh` 启用提交模板和检查。

## 公开内容范围

本仓库记录通用技术目标、需求、学习方法与实验，不收录个人背景或生活叙述。对话中出现的信息不会自动成为公开文档内容。
