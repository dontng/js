# Joint-Studio

简称 **JS**。从 CAN/CAN FD 入门，逐步做出自己能理解、修改和排错的上位机，再接入 ROS2。

只有三个入口：

- [学习](docs/README.md)：知识笔记、参考资料、环境说明。
- [需求](plan/README.md)：现在做什么、有哪些问题、后面怎样推进。
- [工具](labs/README.md)：所有小实验、脚本和上位机代码，统一放这里。

当前还没有实机验证过的程序。先走稳第一步，每轮只做一个小功能。GitHub提供参考和启发，AI协助拆解；看懂、亲手修改和验证后再集成。

公开内容只保留技术需求、公开依据和独立示例，不记录个人背景或内部原件。
