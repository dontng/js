# 学习笔记

这里放“已经理解了什么、下次怎样判断”，外部原文放[资料区](../resources/README.md)，实测步骤放[实验区](../labs/README.md)。

起点接近零基础，先围绕一个可操作问题解释，新缩写首次出现必须说明作用。每篇尽量包括：具体问题、当前理解、一个例子、容易错的地方、下一步怎样验证，以及资料来源。可复制[笔记模板](../templates/note.md)。

主题按需要创建，如 can/、python/、linux/、ros2/。这些是后续方向，不要求先把所有目录填满。现有第一篇：[从一次读取理解通信](can/first-reading.md)。
