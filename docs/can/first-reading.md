# 第一件事：理解一次读取

状态：概念入门；未接入真实设备，具体报文待资料确认。

## 先回答一个问题

上位机点击“读取位置”之后发生什么？程序按设备约定准备信息，交给 CAN 盒发出；关节模组的驱动板处理请求并返回信息，程序将返回数字解释成位置。

CAN 盒是硬件入口，CAN/CAN FD 规定信息的传输方式，CANopen 或厂家协议规定业务内容怎样解释。CAN FD 的加速通常指 BRS（位速率切换），它不是让电机加速的运动命令。具体软件的“加速”选项仍需按手册核对。

## 现在不背哪些东西

暂不背完整帧字段、CANopen 通信对象清单或错误状态编号。实际代码遇到字节、ID、速率等内容时，结合这一条读取逐项解释。

## 第一次验证

取得允许查看的资料后，找到一次真实读取的请求和返回，指出原始信息、位置值和单位的对应关系。在未确认之前不编造 ID、字节或换算系数。
