# CANopen

建立在 [CAN](CAN.md) 之上的一套设备通信约定，进一步规定怎样组织设备参数、状态和数据交换。支持它的设备可以按相应约定交流，而不只是在总线上传字节。

不能因为设备用了 CAN，就认定它用了 CANopen；也不能认定所有电机命令都相同。实际开发仍需对应设备手册。CANopen FD 是相关但不同的协议体系，不能简单理解成给经典 CANopen 勾选 [CAN FD](CAN%20FD.md)。

参考：CiA：CANopen：`https://www.can-cia.org/can-knowledge/canopen`。
