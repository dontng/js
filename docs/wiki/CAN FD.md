# CAN FD

CAN 的扩展，单帧最多可携带 64 字节数据，经典 [CAN](CAN.md) 最多为 8 字节。它还允许使用 [BRS](BRS.md)，让一帧的数据阶段采用另一档、更高的速率。

支持 CAN FD 不等于每帧都启用加速，也不等于自动理解电机指令。[CAN盒](CAN%E7%9B%92.md)、总线上的相关设备及参数配置需要相互兼容。

参考：Kvaser：CAN FD 教程：`https://kvaser.com/can-fd-protocol-tutorial/`。
