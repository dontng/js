# COM口

Windows 给[串口](%E4%B8%B2%E5%8F%A3.md)使用的名称，例如 COM3、COM8。它是软件选择通信入口时看到的名字，不是某一种插头的名称。

[USB](USB.md) 设备可能通过[驱动](%E9%A9%B1%E5%8A%A8.md)提供 COM 口，也可能提供专用接口。看到 USB 插头，不能直接推断必须使用 [串口助手](%E4%B8%B2%E5%8F%A3%E5%8A%A9%E6%89%8B.md)；[CAN盒](CAN%E7%9B%92.md) 要按具体型号确认。

参考：python-can：串口型 CAN 接口：`https://python-can.readthedocs.io/en/stable/interfaces/slcan.html`。
