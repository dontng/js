# 驱动

让操作系统能够与某类硬件配合工作的软件。这里主要指让电脑识别和访问 [CAN盒](CAN%E7%9B%92.md) 的设备驱动。

驱动装好，不等于自己的 [上位机](%E4%B8%8A%E4%BD%8D%E6%9C%BA.md) 已经会收发数据；程序通常还要调用兼容的 [SDK](SDK.md)。是否需要单独安装驱动、支持哪种系统，要按具体设备说明确认。

## 哪些名词与它有关

[CAN盒](CAN%E7%9B%92.md)、[COM口](COM%E5%8F%A3.md)、[Python](Python.md)、[USB](USB.md)、[SDK](SDK.md)。
