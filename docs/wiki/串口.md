# 串口

一种按顺序传送数据的通信接口。电脑软件访问串口时，需要按设备要求设置通信参数、发送内容并读取返回内容。

Windows 常用 [COM口](COM%E5%8F%A3.md) 名称表示可访问的串口。[串口助手](%E4%B8%B2%E5%8F%A3%E5%8A%A9%E6%89%8B.md) 是操作它的现成软件；部分 [CAN盒](CAN%E7%9B%92.md) 提供串口接口，但串口与 [CAN](CAN.md) 不是同一回事。

参考：pySerial 简介：`https://pyserial.readthedocs.io/en/latest/shortintro.html`。
