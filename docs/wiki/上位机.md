# 上位机

电脑上用来连接设备、查看状态或发送指令的软件。这里说的上位机，是你准备自己编写的桌面工具。

它可以用 [Python](Python.md) 编写，通过 [PyQt](PyQt.md) 做窗口，通过 [SDK](SDK.md) 访问 [CAN盒](CAN%E7%9B%92.md)。某些设备通过 [COM口](COM%E5%8F%A3.md) 访问，但不是所有设备都如此；上位机也不等于[串口](%E4%B8%B2%E5%8F%A3.md)软件。
