# Python

一种编程语言。你可以用它写接收数据、换算数值、保存文件等程序，也可以借助 [PyQt](PyQt.md) 编写 [上位机](%E4%B8%8A%E4%BD%8D%E6%9C%BA.md) 的窗口。

Python 本身不会自动认识 [CAN盒](CAN%E7%9B%92.md)；访问设备仍需要兼容的[驱动](%E9%A9%B1%E5%8A%A8.md)和 [SDK](SDK.md) 或通信库。

## 哪些名词与它有关

[上位机](%E4%B8%8A%E4%BD%8D%E6%9C%BA.md)、[Qt](Qt.md)、[SDK](SDK.md)、[PyQt](PyQt.md)。
