# 串口助手

一种现成的串口调试软件：选择 [COM口](COM%E5%8F%A3.md)，设置参数，发送数据，查看接收内容。它可以暂时代替你自己的程序，帮助确认通信是否正常。

它通常不理解温度、速度等业务含义，也不是自动监听另一个 [上位机](%E4%B8%8A%E4%BD%8D%E6%9C%BA.md) 的工具。只有设备确实提供兼容的 [串口](%E4%B8%B2%E5%8F%A3.md) 接口时才适用；用专用接口访问的 [CAN盒](CAN%E7%9B%92.md) 应使用相应厂商工具。

参考：pySerial 串口终端示例：`https://pyserial.readthedocs.io/en/latest/tools.html#module-serial.tools.miniterm`。
