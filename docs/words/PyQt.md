# PyQt

让 [Python](Python.md) 调用 [Qt](Qt.md) 的一套工具，常用于制作 [上位机](%E4%B8%8A%E4%BD%8D%E6%9C%BA.md) 的窗口、按钮和表格。可以先理解为“用 Python 使用 Qt”，不是用 Python 重写了一套 Qt。

它主要解决界面与交互问题；设备连接和数据含义还要通过 [SDK](SDK.md)、设备协议等解决。

参考：Riverbank：PyQt：`https://www.riverbankcomputing.com/software/pyqt/intro`。
