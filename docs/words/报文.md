# 报文

通信中一次按规定格式组织并传送的消息。对于 [CAN](CAN.md) 接收程序，你通常会看到时间、ID、数据长度、数据内容，以及相关标记。

可以先把 ID 理解成消息标识，把数据内容理解成需要按协议解释的字节。ID 不必然等于设备地址，某个字节也不天然代表温度；[上位机](%E4%B8%8A%E4%BD%8D%E6%9C%BA.md) 要按设备协议或 [CANopen](CANopen.md) 等约定解释。

参考：python-can：消息字段：`https://python-can.readthedocs.io/en/stable/message.html`。
