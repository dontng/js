# SDK

软件开发工具包，通常包括给程序调用的接口、说明文档和示例。厂商提供 CAN 盒 SDK，是为了让你自己的 [上位机](%E4%B8%8A%E4%BD%8D%E6%9C%BA.md) 能访问硬件。

[驱动](%E9%A9%B1%E5%8A%A8.md) 解决操作系统与设备配合的问题，SDK 帮助你的程序使用设备；两者有时随同一个安装包提供。用 [Python](Python.md) 调用 SDK 是否方便、是否支持当前系统，要看厂商支持。

参考：Kvaser：CANlib 开发接口：`https://kvaser.com/canlib-webhelp/page_canlib.htm`。
